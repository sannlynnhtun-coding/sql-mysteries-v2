သင်ကြားရန်အကြံပြုချက်

  • Learner ကို result table ဖတ်ခိုင်းပြီး နောက် query မရေးမီ clue ကို စကားဖြင့် ပြန်ပြောခိုင်းပါ။
  • Query syntax တိတိကျကျတူဖို့ မလိုပါ။ Column နဲ့ rows မှန်ကန်သော equivalent SELECT ကို website က လက်ခံသည်။
  • Hint 1 ကို concept အတွက်၊ Hint 2 ကို syntax scaffold အတွက် သုံးပြီး full query ကို နောက်ဆုံးမှ ဖွင့်ပါ။
  • သင်ခန်းစာအတွက် 35–50 မိနစ် ခွဲထားပါ။ JOIN steps နှစ်ခုအတွက် အချိန်ပိုပေးပါ။

Canonical solution path

Step-by-step answers

01 · SELECT

Table စာရင်း

SELECT name
FROM sqlite_master
WHERE type = 'table';
Expected: crime_reports, interviews, memberships, people — main table ၄ ခုအတိအကျ။

02 · WHERE + AND

Target report

SELECT *
FROM crime_reports
WHERE type = 'theft'
  AND date = '2024-03-10'
  AND city = 'SQL Village';
Expected: report_id 102။ Description မှ Padauk Street အမြင့်ဆုံးအိမ်နံပါတ်နှင့် Inya Road မှ Thiri ကို တွေ့ရမည်။

03 · ORDER BY + LIMIT

ပထမသက်သေ

SELECT *
FROM people
WHERE address_street = 'Padauk Street'
ORDER BY address_number DESC
LIMIT 1;
Expected: person_id 3, U Hla Aung, age 61, house 88.

04 · LIKE

ဒုတိယသက်သေ

SELECT *
FROM people
WHERE name LIKE 'Thiri%'
  AND address_street = 'Inya Road';
Expected: person_id 4, Thiri Win, age 27, house 18.

05 · JOIN

Interview clues

SELECT p.name, i.transcript
FROM people AS p
JOIN interviews AS i
  ON p.person_id = i.person_id
WHERE p.person_id IN (3, 4);
Expected: U Hla Aung က FitLife Gym လိုဂိုကိုမြင်ခဲ့ပြီး Thiri Win က gold membership card ကိုမြင်ခဲ့သည်။

06 · FINAL JOIN

တရားခံ

SELECT p.name, p.age, m.gym_name, m.membership_status
FROM people AS p
JOIN memberships AS m
  ON p.person_id = m.person_id
WHERE m.gym_name = 'FitLife Gym'
  AND m.membership_status = 'gold';
Expected: Nandar Hlaing | 29 | FitLife Gym | gold.

Acceptance checklist

  • □ SELECT နဲ့ WHERE ကိုရှင်းပြနိုင်သည်
  • □ DESC နှင့် LIMIT 1 ကိုသုံးနိုင်သည်
  • □ LIKE wildcard ကိုနားလည်သည်
  • □ person_id ဖြင့် JOIN လုပ်နိုင်သည်
  • □ Query result မှ clue ကိုဖတ်နိုင်သည်
  • □ Advanced subquery မလိုဘဲ အမှုပြီးနိုင်သည်
